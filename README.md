# AI Model Hub বাংলা

এক জায়গায় জনপ্রিয় AI মডেল ও অ্যাপ খুঁজুন, তাদের কাজের ধরন জানুন এবং আপনার প্রয়োজন অনুযায়ী তুলনা করুন।

## বৈশিষ্ট্য
- সম্পূর্ণ বাংলা ইন্টারফেস
- AI মডেল ও অ্যাপ ডিরেক্টরি
- কাজ অনুযায়ী ক্যাটাগরি ও সার্চ
- সর্বোচ্চ তিনটি টুল তুলনা
- মোবাইল ও ডেস্কটপ উপযোগী ডিজাইন

## GitHub Pages
এই রিপোজিটরির `main` ব্রাঞ্চের `/(root)` ফোল্ডার থেকে GitHub Pages চালু করুন। Repository Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/(root)` নির্বাচন করে Save করুন।

তথ্য ও মডেলের সক্ষমতা পরিবর্তনশীল; সর্বশেষ বিবরণের জন্য সংশ্লিষ্ট প্রতিষ্ঠানের অফিসিয়াল ওয়েবসাইট দেখুন।
