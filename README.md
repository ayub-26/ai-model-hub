# AI Model Hub বাংলা

এক জায়গায় জনপ্রিয় AI মডেল ও অ্যাপ খুঁজুন, তাদের কাজের ধরন জানুন এবং আপনার প্রয়োজন অনুযায়ী তুলনা করুন।

## বৈশিষ্ট্য
- বাংলা ইন্টারফেস
- AI মডেল ও অ্যাপ ডিরেক্টরি
- সার্চ ও ক্যাটাগরি
- ফোন ও কম্পিউটারে ইনস্টলযোগ্য PWA
- সার্ভিস ওয়ার্কারের মাধ্যমে বেসিক অফলাইন ক্যাশ

## ফোনে ইনস্টল
1. Chrome বা সমর্থিত ব্রাউজারে https://ayub-26.github.io/ai-model-hub/ খুলুন।
2. Chrome-এর তিন ডট মেনু থেকে **Install app** অথবা **Add to Home screen** চাপুন।
3. নির্দেশনা অনুসরণ করে ইনস্টল নিশ্চিত করুন।

iPhone/iPad-এ Safari দিয়ে সাইট খুলে **Share → Add to Home Screen** নির্বাচন করুন।

## কম্পিউটারে ইনস্টল
1. Chrome বা Edge-এ ওয়েবসাইট খুলুন।
2. ঠিকানার পাশে Install আইকন থাকলে সেটিতে ক্লিক করুন; না থাকলে ব্রাউজারের মেনু থেকে **Install AI Model Hub** নির্বাচন করুন।
3. Install নিশ্চিত করুন।

## ডেভেলপার নোট
PWA ফাইল:
- `manifest.webmanifest` — অ্যাপের নাম, রং ও ডিসপ্লে সেটিং
- `sw.js` — সার্ভিস ওয়ার্কার ও অফলাইন ক্যাশ
- `app-icon.svg` — অ্যাপ আইকন
- `index.html` — ইনস্টল বাটন ও সার্ভিস ওয়ার্কার রেজিস্ট্রেশন

GitHub Pages অবশ্যই HTTPS-এ প্রকাশিত থাকতে হবে। নতুন ফাইল আপডেট হলে `sw.js`-এর `CACHE_NAME` সংস্করণ বাড়িয়ে দিন।

## GitHub Pages
Repository Settings → Pages → Build and deployment → GitHub Actions নির্বাচন করুন (workflow `.github/workflows/pages.yml` ব্যবহার করে)।

AI মডেলের সক্ষমতা, মূল্য ও সুবিধা পরিবর্তনশীল; সর্বশেষ তথ্যের জন্য সংশ্লিষ্ট প্রতিষ্ঠানের অফিসিয়াল ওয়েবসাইট দেখুন।
